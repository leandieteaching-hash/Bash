# WCAG 2.2 AA compliance baseline

Studio OS targets WCAG 2.2 Level AA. The release gate covers keyboard operation, visible focus, landmarks, accessible names, form errors, contrast, reflow at 320 CSS pixels, reduced motion, and screen-reader smoke tests.

## Required evidence

- Automated axe scans for authenticated routes.
- Keyboard-only completion of critical workflows.
- NVDA or VoiceOver smoke test evidence.
- Contrast verification for design tokens and status states.
- No critical or serious accessibility violations.

Known exceptions require an owner, remediation date, affected users, and an approved compensating control.
